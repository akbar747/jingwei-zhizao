# 测试说明

## 自动测试分类

| 测试文件 | 验证内容 |
|---|---|
| `tests/domain/test_models.py` | PatternGrid尺寸、坐标、复制和空值边界 |
| `tests/domain/test_compiler.py` | 提升列映射、花本去重、编号顺序和空纹样警告 |
| `tests/domain/test_weaver.py` | 织物矩阵生成和非法计划拒绝 |
| `tests/ui/test_canvas_geometry.py` | 鼠标坐标到网格单元的换算和边界 |
| `tests/ui/test_pattern_canvas.py` | 左键绘制、右键擦除、橡皮模式、信号去重 |
| `tests/test_compile_service.py` | 应用层编译服务正确调用领域编译器 |
| `tests/test_smoke.py` | 主窗口、报告更新和结果过期状态 |

## 每轮提交前检查

- [ ] 运行完整测试命令，所有测试通过。
- [ ] 运行 `python -m jingwei --smoke-test`，退出码为0。

- [ ] 确认没有提交 `.venv/`、缓存、截图临时文件和密钥。

## 性能观察

当前MVP只要求16×16至64×64点阵。64×64纹样的编译应保持即时响应；如果超过100ms，需要记录机器配置并分析热点，而不是提前引入复杂优化。
