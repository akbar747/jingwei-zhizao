## 一、设计目标

### 1.1 用户目标

用户进入软件后，应能在不阅读长说明书的情况下完成：

1. 画出一个简单纹样；
2. 点击编译并看懂生成了多少条花本指令；
3. 播放或单步执行织造；
4. 对照原纹样检查织物结果；
5. 导出织物图和工程文件。

### 1.2 设计原则

- **流程固定**：顶部始终显示“设计 → 编译 → 织造 → 成果”四步进度。
- **当前任务突出**：中央区域只承载当前页面的主任务，辅助信息放在左右侧栏。
- **结果有依据**：任何动画状态都能在右侧查看对应数据。
- **错误可定位**：错误信息必须指出模式、行号/梭次、原因和处理方法。
- **不依赖颜色**：状态同时用文字、图标形状和颜色表示。
- **窗口自适应**：最低支持 1180×720，推荐 1440×900。

### 3.1 顶部模式导航

- 四个模式按钮为互斥选择。
- 未满足前置条件时按钮不消失，但显示锁定原因：
  - 未编译时，织造按钮可点击但进入后显示“请先编译”。
  - 纹样为空时，编译按钮可点击并在右侧显示“纹样为空”。
- 当前模式以底色、左侧短线和文字加粗三重方式表现。
- 修改纹样后，后续模式显示“结果已过期”状态。
- 禁止用只有颜色变化的方式表达状态。

### 3.2 左侧工具区

左侧工具区随模式变化：

| 模式 | 工具 |
|---|---|
| 设计 | 画笔、橡皮、直线、矩形、填充、镜像、撤销、重做、清空 |
| 编译 | 编译、重新编译、花本排序、显示同色指令、跳转到行 |
| 织造 | 播放/暂停、上一步、下一步、重置、速度、跟随织物 |
| 成果 | PNG、WIF、CSV、保存工程、打开导出目录 |

工具按钮必须有文字提示或工具提示。核心动作不隐藏在右键菜单中。

### 3.3 右侧检查器

右侧检查器不是固定信息板，而是随选择变化：

- 选中纹样单元：显示列/行坐标、提升状态。
- 选中花本指令：显示指令编号、提升集合、对应纹样行、出现次数。
- 选中某一梭：显示提升、开口、投梭方向、打纬状态。
- 选中织物单元：显示来源纹样单元、梭次、经线编号、最终交织值。

### 4.2 绘图交互

- 左键按下开始绘制，拖动连续绘制。
- 右键不直接清空，避免误操作；橡皮使用工具按钮或 `E`。
- 画笔值与颜色调色板绑定。
- 直线和矩形显示拖拽预览，释放后一次性提交，放入同一条撤销记录。
- 填充工具使用四连通填充，画布边界外不处理。
- 镜像分为左右镜像、上下镜像；操作前显示操作对象，不直接覆盖未保存内容。
- 网格线和单元边界在低缩放下自动简化，但单元中心点仍可见。
- 鼠标悬停时高亮行列坐标，并在状态栏显示坐标。

### 4.4 画布规格

新建工程时可选择：

- 快速规格：8×8、16×16、24×24、32×32。
- 自定义：经线 4–64，纬线 4–64。
- 默认 16×16，适合课堂演示。
- 画布尺寸改变前，如果已有内容，必须确认“缩放保留/裁剪/取消”。

### 4.5 纹样校验

右侧检查器实时显示：

- 是否为空；
- 已填充单元数量；
- 有效纹样行数量；
- 是否为空白行；
- 是否存在超出当前工具能力的值；
- 是否需要重新编译。

## 五、模式二：纹样编译模块

### 5.1 布局

```text
┌──────────────┬───────────────────────────┬───────────────────────┬─────────────┐
│ 编译控制      │ 原始纹样行                 │ 花本指令表            │ 指令详情     │
│              │                           │                       │             │
│ [编译花本]    │ 行01 ■ □ ■ □ ■ □         │ C01 101010            │ 对应行：01  │
│ 保留空行：否  │ 行02 ■ □ ■ □ ■ □         │ C02 010101            │ 出现：4次   │
│ 指令排序：首次│ 行03 ■ ■ □ □ ■ ■         │ C03 110011            │ 提升集合：  │
│              │ ...                       │ ...                   │ 1,2,5,6     │
│              │                           │                       │ 压缩率：62% │
└──────────────┴───────────────────────────┴───────────────────────┴─────────────┘
```

### 5.2 编译动作

1. 用户点击“编译花本”。
2. 软件先执行输入检查。
3. 显示短暂进度状态，不弹遮挡式加载框。
4. 完成后，原始纹样行与花本指令建立颜色/编号映射。
5. 点击某一行时，高亮所有使用该花本指令的原始行。
6. 点击某条指令时，高亮其对应行和右侧详情。

### 5.3 编译报告

报告分为三个等级：

- **信息**：原始行数、唯一指令数、压缩率、首次出现顺序。
- **警告**：全部为空、大量重复空白行、纹样尺寸过大。
- **错误**：矩阵值非法、行长度不一致、内部映射失败。

示例文本：

> 原始纹样 16 行，唯一提升组合 7 条，压缩后指令 7 条，压缩率 56.3%。第 8–11 行复用 C03。

### 5.4 可追溯交互

- 悬停某一原始行：显示其花本编号。
- 悬停某条花本：显示首次出现行和出现次数。
- 双击某条花本：打开该指令的全部出现位置。
- 编译结果变化后，旧的织造预览标记为过期，不允许无提示直接播放旧结果。

## 六、模式三：织造模拟预览模块

### 6.1 布局

```text
┌───────────────┬───────────────────────────────────────────┬──────────────────┐
│ 织造控制       │             织机半剖面视图                 │ 状态解释          │
│ [播放] [暂停]  │  花楼/提升装置                             │ 当前梭次 7/16    │
│ [◀] [▶] [重置]│  ────────────────────                     │ 动作：投梭        │
│ 速度：1.0x     │  经线  ||||||||||||||||                   │ 提升集合：       │
│ 跟随织物：开   │  综片  ▔▔▔▔▔▔▔▔▔▔▔▔                   │ 1,3,4,8,12      │
│               │  梭子  ────────────────▶                 │ 方向：左→右      │
│               │  筘     ▁▁▁▁▁▁▁▁▁▁▁▁                   │ 已织行：6/16      │
├───────────────┼───────────────────────────────────────────┼──────────────────┤
│ 当前纹样行     │              织物生长预览                  │ 工艺语言/计算语言 │
│ 行07 ■ □ ■ ■  │   ■ ■ ■ ■ ■ ■ ■ ■ ■ ■ ■ ■ ■ ■ ■ ■        │                  │
│               │   ■ □ □ ■ □ □ ■ □ □ ■ □ □ ■ □ □ ■        │                  │
└───────────────┴───────────────────────────────────────────┴──────────────────┘
```

### 6.2 单梭动作分解

每一梭按四个阶段显示，但时间轴上仍以一梭为一个主节点：

1. **提升**：显示本次被选中的经线/花本钩。
2. **开口**：经线分层，形成梭口。
3. **投梭**：梭子从左到右或右到左移动。
4. **打纬**：纬线被推向织口，织物矩阵增加一行。

右侧文字同步切换：

> 提升：花本 C03 将第1、2、5、6根经线抬起。  
> 开口：上下两层经线分离。  
> 投梭：梭子从右向左穿过梭口。  
> 打纬：第7行纬线固定，织物已形成7/16。

### 6.3 播放控制

- **单步**：每次完成一个梭次，适合课堂讲解。
- **播放**：按固定节奏连续执行，速度范围 0.5×–2.0×。
- **暂停**：保留当前状态，不重置。
- **上一步**：回退一个完整梭次，须能从确定状态重建。
- **重置**：回到第0梭，但保留编译结果。
- 播放期间切换模式：先暂停并保留状态，不静默丢失进度。

### 6.4 视觉映射

- 抬起经线：靛青粗线。
- 未抬起经线：灰色细线。
- 当前纬线：朱砂色。
- 已完成织物：米白底 + 墨色交织点。
- 当前选中单元/花本：金色描边。
- 动画速度变化不能改变最终织物结果。

## 七、模式四：成果与导出

### 7.1 布局

```text
┌──────────────────────┬───────────────────────────────┬─────────────────────┐
│ 原纹样                │ 织物成品                       │ 导出                │
│ ■ □ ■ □ ■ □          │ ■ ■ □ ■ ■ □ ■ ■               │ [导出PNG]           │
│ □ ■ □ ■ □ ■          │ □ ■ ■ □ ■ ■ □ ■               │ [导出WIF]           │
│                      │                               │ [导出CSV]           │
├──────────────────────┼───────────────────────────────┼─────────────────────┤
│ 编织矩阵              │ 缩放与显示                     │ 文件信息             │
│ 1 0 1 0 1 0          │ [适应] [100%] [放大] [缩小]     │ 工程：...            │

└──────────────────────┴───────────────────────────────┴─────────────────────┘
```

### 7.2 导出规则

- `PNG`：默认导出织物成品图，可选原纹样/织物并排图。
- `CSV`：行=纬线梭次，列=经线编号，值为最终交织状态。
- `WIF`：导出标准织造交换文件，显示映射说明和兼容性提示。
- `.jwg`：保存完整工程，包括版本、画布、编译结果和当前状态。
- 导出前检查目标路径是否可写；失败时保留用户输入，不关闭对话框。

## 八、状态机与数据联动

```text
空工程
  └─ 画布发生修改 → 设计已修改
       └─ 点击编译 → 编译成功
            └─ 进入织造 → 织造中
                 ├─ 暂停 → 已暂停
                 ├─ 完成 → 已完成
                 └─ 返回设计 → 结果过期

任何模式：
  保存 → 当前状态写入 .jwg
  打开 → 替换当前状态（如有未保存修改先确认）
  导出 → 只读取当前结果，不修改工程状态
```

### 8.1 关键信号

| 触发 | 响应 |
|---|---|
| 画布修改 | 清除“编译有效”标记，触发轻量校验 |
| 编译完成 | 更新 `WeavePlan`，启用织造 |
| 选中纹样行 | 高亮对应花本，更新右侧详情 |
| 选中花本 | 高亮所有来源行 |
| 执行到第N梭 | 更新织机视图、织物矩阵和时间轴 |
| 导出完成 | 状态栏显示绝对路径和“打开目录”入口 |
| 工程损坏 | 进入只读恢复模式，不覆盖原文件 |

- 主按钮高度 36px；次按钮 32px。
- 图标使用简单的自绘SVG或Qt标准图标。
- 所有图标必须有工具提示和可访问名称。
- 色块不能单独表达成功/失败，必须配文字。

## 十、异常与边界状态

| 场景 | 行为 |
|---|---|
| 画布为空 | 编译按钮可点击，但右侧显示“请先绘制至少一个单元” |
| 纹样行长度不一致 | 阻止编译，指出具体行号 |
| 工程文件损坏 | 显示错误详情，允许另存恢复 |
| 导出目录只读 | 不覆盖文件，提示选择其他目录 |
| 织造过程中点击设计 | 暂停并提示“修改纹样会使当前织造结果过期” |
| 窗口被缩放 | 中央画布自适应，工具栏和检查器不重叠 |
| 高DPI | 以设备像素比渲染网格和文本，禁止文字被截断 |

## 十二、可验证的UI验收标准

### 12.1 设计模式

- 用户可以在2分钟内画出16×16以内的简单纹样。
- 撤销/重做至少支持50步。
- 画布缩放、拖动和坐标显示正常。
- 修改纹样后，编译状态立即变为“已过期”。

### 12.2 编译模式

- 编译后能显示原始行、花本编号和压缩报告。
- 相同输入连续编译得到相同结果。
- 选择任意原始行都能定位对应花本。
- 选择任意花本都能定位所有来源行。

### 12.3 织造模式

- 能单步播放并看到提升、开口、投梭、打纬的全过程。
- 时间轴位置与当前梭次、右侧状态、织物矩阵一致。
- 暂停、继续、上一步、重置后状态可恢复。
- 播放速度不改变最终结果。

### 12.4 成果模式

- 原纹样、织物预览和导出矩阵一致。
- PNG、CSV、WIF 均可导出且可再次打开。
