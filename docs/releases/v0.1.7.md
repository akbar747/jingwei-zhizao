# 经纬智造 v0.1.7

首个可安装的MVP版本，将Release构建失败详情写入GitHub运行摘要，避免公开日志权限导致无法定位错误。

## 下载选择

- `JingweiZhizao-Setup-0.1.7.exe`：推荐。双击安装，无需管理员权限，安装后从开始菜单或桌面快捷方式启动。
- `JingweiZhizao-Portable-0.1.7.zip`：便携版。解压后运行 `JingweiZhizao.exe`，不需要安装Python。
- `SHA256SUMS.txt`：发布文件完整性校验值。

## 已实现

- 16×16默认点阵画布。
- 左键绘制、右键擦除、橡皮模式、清空纹样。
- 纹样行解析、提升经线提取、重复行花本复用。
- 花本编号、出现次数、压缩率和编译报告。
- 修改纹样后的结果过期提示。
- 织物矩阵生成与核心算法测试。

## 已知限制

## 安装环境

- Windows 10/11 64位。
- 无需Python。
- 核心功能离线运行。
- 建议1366×768及以上分辨率。
