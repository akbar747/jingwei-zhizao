# 经纬智造 v0.3.0 发布说明

发布日期：2026-10-05

## 版本主题：把织造工坊做成真正好玩的作品

v0.3.0 在原有“绘制 → 编译花本 → 逐梭织造”闭环之上，补齐了完整的游戏循环，
让同一件纹样有收藏价值、有重玩目标，也有即时的视觉与听觉反馈。

## 新增玩法

### 三颗独立星级：形 / 技 / 速

- ★ **形**：纹样匹配度 ≥ 98%，考察对传统纹样的忠实复现。
- ★ **技**：花本压缩率 ≥ 订单门槛，考察对可编程提花指令的理解。
- ★ **速**：在订单时限内完成，考察织造效率。

三颗星互相独立，因此同一件作品有明确的重玩目标。

### 织坊订单变体

进入关卡时随机获得订单，让同一关有不同体验：

- 常规订单：标准时限。
- 加急订单：时限压缩 45%。
- 精品订单：花本压缩率需达 85%。
- 记忆订单：目标纹样只预览 3 秒。
- 盲织订单：隐藏实时匹配提示。

### 纹样收藏册与进度存档

- 三件目标纹样可收藏，附民族文化注解与最佳成绩。
- 关卡逐级解锁，进度写入 `%APPDATA%\JingweiZhizao\progress.json`。
- 完成关卡后可在收藏册内一键导出 PNG 织锦作品卡。

### 纹样炼成（对称工具）

- 左右镜像、上下镜像、四向圆满、对角翻折。
- 一键把一小段手绘扩展成传统织锦常见的对称构图。
- 整次炼成可作为一步撤销。

### 编辑手感

- 整笔撤销 / 重做：一次拖动算一笔，`Ctrl+Z` / `Ctrl+Y`。
- 编译连击反馈：`花本压缩 75% · 连击 x3 · 复用 6 行`。
- 程序化音效：编译、梭子、通关三类提示音。

### 程序化灵感纹样

- 同一随机种子永远生成同一件纹样，可复现、可出题。
- 内置四种传统风格：天圆回纹、菱格锦、云雷纹、团花纹。

### 通关庆典

- 织造完成后弹出结算层，展示成品织物、扩散粒子与三颗星。
- 直接提供「导出作品卡」「再织一次」「下一关」「返回工坊」。

## 技术说明

- 纯 Python 领域层，所有核心逻辑均有单元测试。
- 运行不联网，音效与作品卡均为程序化生成，无外部素材依赖。
- Windows 离线桌面软件，PySide6-Essentials。
